# Walnut Studio: restyling a Blender room from one reference

I used GPT-6 Astra to ask whether one reference image could guide an editable restyle of an existing Blender scene. The layout was already there. The workflow kept it and changed the look with scripted walnut and olive materials, warm practical lights, a cool window light, and three camera moves.

This is a test of reference-guided scene editing. Here, AI is being used to translate a visual direction into changes that remain editable in Blender. The harder question is consistency: do the material, lighting, and camera choices still make sense when the same room is viewed from different angles? The available images do not quantify that, so this is a visual study rather than spatial reconstruction or a benchmark.

The September 7 images show the result. The walnut and olive palette works for me, though the plants and furniture still feel procedural. I don't have a reliable total time for this run. Next time I will time the build and render separately, use real dimensions, improve asset detail, then change one thing and check each camera view for local edit consistency.

With the local scene, press Numpad 0 for camera view, then Space to preview the camera movement. The repository documents scripts and workflow, excludes the base scene, and is not a complete scene download. Read [Code and workflow](README.md).
